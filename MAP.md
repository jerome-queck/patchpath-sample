# Map

PatchPath route preview is the runnable public evidence repository for PatchPath's controlled judge
path.

Start with `README.md`, run the product from `index.html`, then follow the candidate issue and
`CONTRIBUTING.md`.

| Area | What lives there | Entry point |
| --- | --- | --- |
| Browser product | Static shell and route-preview interaction | `index.html` |
| Product source | Empty-state behavior, browser mount, and local styling | `src/main.ts` |
| Behavioral checks | Rendered states and meaningful interaction changes | `test/route-preview.test.ts` |
| Contribution guidance | Setup, evidence, scope, and contribution process | `README.md` |
| Automation | Clean-checkout verification | `.github/workflows/ci.yml` |
